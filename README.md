# Perfume Inspiration Finder

A feature-rich, single-page web application designed to help users explore and find inspiration for "dupe" perfumes available on the Shobi website ([leparfum.com.gr/en/](https://leparfum.com.gr/en/)).

This application is built with vanilla JavaScript and Tailwind CSS and loads its perfume data from a local JSON database.

## Features

* **Dynamic Data Loading:** Perfume data is loaded asynchronously from a local JSON file, making the collection easy to update.
* **Advanced Search & Filtering:** Search and filter the perfume database using the available attributes.
* **Favorites System:** Save favorite perfumes locally in the browser.
* **Customizable Themes:** Switch between the available visual themes.
* **Responsive Layout:** Browse the database on desktop and mobile devices.

## How to Use

1. Clone or download the repository.
2. Keep the perfume database JSON file in the same project structure expected by `script.js`.
3. Open `index.html` in a modern web browser or publish the repository with GitHub Pages.
